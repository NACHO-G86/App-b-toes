# App-b-toes — Elige tu destino 🎲

Una aplicación web interactiva desarrollada con HTML, CSS y JavaScript Vanilla con un diseño moderno, centrado y limpio.

## Características

- **Título**: "Elige tu destino" con tipografía moderna y fondo con resplandor ambiental.
- **Dos botones interactivos**: Un botón rojo (*Camino Rojo*) y un botón azul (*Camino Azul*) con efectos hover, brillo y sombreado neon.
- **Resultado aleatorio**: Al pulsar cualquiera de los botones, se muestra aleatoriamente *"Has ganado"* (con celebración y confeti) o *"Has perdido"* (con efecto shake).
- **Botón para volver a jugar**: Restaura la partida de forma fluida.
- **Efectos extra**: Contador de victorias y derrotas, efectos de sonido sintetizados nativos con Web Audio API y animación de confeti en `<canvas>`.

## Cómo abrirla

Simplemente abre el archivo [`index.html`](index.html) en tu navegador web favorito (haciendo doble clic o arrastrándolo a la ventana del navegador).
